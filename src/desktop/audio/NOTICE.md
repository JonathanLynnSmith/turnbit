# NAudio Windows helper dependencies

NAudio.Core.dll and NAudio.Wasapi.dll are the unmodified netstandard2.0 assemblies
from the official NuGet NAudio.Core / NAudio.Wasapi 2.4.0 packages. This target
runs in Windows PowerShell/.NET Framework. No runtime download, driver
installation, or network connection is required.

Source: https://github.com/naudio/NAudio
Packages: https://www.nuget.org/packages/NAudio.Core/2.4.0 and
https://www.nuget.org/packages/NAudio.Wasapi/2.4.0
